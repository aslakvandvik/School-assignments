# Java OOP Projects

Java/Maven/Swing projects from an object-oriented programming course.

- **lab0-setup/** through **lab3-intro/** — early weekly labs (setup, basics, intro exercises)
- **testing-lab-java/** — a lab focused on unit testing
- **generics-lab-java/** — a lab on Java generics
- **grid-viewer-java-maven/** — a small Swing app for viewing a grid
- **clickable-grid-java-maven-swing/** — a Swing app with an interactive, clickable grid
- **tetris-clone-java-maven-swing/** — the semester project: a Tetris clone built with Swing, using the MVC pattern

Each project is a standalone Maven module with its own `pom.xml` and `src/`.
