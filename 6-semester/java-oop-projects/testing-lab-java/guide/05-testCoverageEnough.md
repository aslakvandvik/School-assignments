# **🔎 Dekker testene alt?**

Vi har nå skrevet tester som fanger opp vanlige feil for alle operatorklassene. Det betyr vel at **alt fungerer som det skal** … eller?


## **📌 Tester dekker aldri alt**
Selv med gode tester som fanger vanlige feil, kan det fortsatt være **ukjente feil** i programmet. **Gode tester** finner de vanligste feilene, men ikke nødvendigvis **alle**.
